# 工具执行与默认视觉能力

文件读取状态保存在 Agent 会话中，异步和后台工具共享记录。只有成功读取文本或成功写入后才允许编辑；路径先规范化，清空或替换会话上下文会重置记录。

网页搜索按用户每轮输入确定预算：简单事实问题默认 2 次，明确要求调研、综述或比较时默认 8 次。可在 `aero.yaml` 中配置：

```yaml
search_simple_budget: 2
search_research_budget: 8
```

模型不能自行提高本轮预算。查询仅去除首尾空白并合并连续空白，全部搜索选项参与去重。相同查询复用原结果和调用 ID，包括失败、未知结果；不会再次执行或计费。达到预算后移除搜索工具，批量调用也不能突破预算。工具结果保留来源、状态、证据和剩余预算；调试日志记录执行、复用次数及停止原因，不记录查询正文。Relay 仍只对成功搜索收费。

官方账户已登录且 `vision.mode` 为 `unconfigured` 时，自动使用 Relay，发送 `model=auto`，文本使用 BYOK 也适用。明确设置的独立视觉、复用主模型和官方指定模型会保留。实际视觉模型由 Relay 生效的视觉队列决定；旧会话无需重新设置，客户端更新后需重启。

官方视觉图片先由客户端直传 OSS 的 `public/vision-inference/` 公共前缀，再将带有效期的图片链接发送给 Relay。图片不占用户私有云空间；部署时先更新 Relay，再更新客户端。视觉模型等待超时为 120 秒。

当前客户端发布隐藏 BYOK 与独立视觉配置入口。首次启动直接登录官方账号，文本通过官方 Relay，视觉固定使用官方 `auto` 路由；已有本地 BYOK 配置不会使客户端继续走自带密钥。供应商适配器、配置模型、凭据存储及 BYOK 配置组件保留，客户端策略由 `BYOK_UI_ENABLED` 控制。此限制同时适用于终端与本地浏览器界面，浏览器设置入口改为账户与额度。
